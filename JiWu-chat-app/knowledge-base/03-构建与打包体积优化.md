# 构建与打包体积优化

## 构建脚本

```bash
pnpm dev                  # Nuxt 开发服务器
pnpm electron:dev:full    # 同时起 Nuxt dev + Electron（桌面开发）
pnpm generate             # 仅 Web 静态生成
pnpm generate:dist        # 壁纸生成 + nuxt generate + 拷贝 dist（桌面前置）
pnpm electron:build       # 桌面打包（注入壁纸 CDN base）
pnpm electron:build:prod  # NODE_ENV=production 的桌面打包
pnpm electron:pack        # 仅打目录（--dir），不生成安装包
```

`electron:build` 实际命令：

```json
"electron:build": "cross-env NUXT_PUBLIC_WALLPAPER_BASE=https://jiwuchat.com npm run generate:dist && electron-builder && node scripts/clean-release.js"
```

## electron-builder 配置要点

- 输出目录 `release`，`asar: true`，`compression: maximum`。
- `win.target` 仅 `nsis` + `x64`（`artifactName`: `JiwuChat_${version}_${arch}-setup.${ext}`）。
- 图标 `build/icon/logo.ico`，语言 `zh-CN`，`afterPack: scripts/after-pack.js`。
- `files`：

```json
["dist/**/*", "!dist/theme/**/*.mp4", "electron/**/*", "!electron/**/*.test.js", "!electron/**/*.spec.js", "!node_modules/**/*", "package.json"]
```

## 体积优化三轮改动

1. **去 ia32**：`win.target.arch` 由 `[x64, ia32]` 改为仅 `x64`，消除 381MB 的 ia32 包与 768MB 合并包。
2. **去 public 重复打包**：`files` 原同时列 `dist/**/*` 和 `public/**/*`，而 `dist` 已含 `public`，
   导致媒体重复约 146MB；删除 `public/**/*` 项。
3. **主题视频改 CDN**：安装包排除 `!dist/theme/**/*.mp4`（约 145MB 视频不进包），
   运行时从 `https://jiwuchat.com/theme` 拉取；海报（0.44MB）保留做离线兜底。

## 体积结果

| 阶段 | 产物 |
|---|---|
| 优化前 | 768MB（合并）+ 381MB(ia32) + 388MB(x64) |
| 优化后 | 仅 `JiwuChat_1.0.4_x64-setup.exe`，约 100–130MB |
