# 极物聊天项目概览

## 产品定位

极物聊天（JiWuChat / JiwuChat）是一款基于 Nuxt3 + Electron 的桌面/Web 即时通讯软件，
当前版本 `1.0.4`，App ID `com.jiwu.chat`，产品名「极物聊天」。功能覆盖即时消息、音视频通话（WebRTC P2P）、
思维导图、Markdown 富文本、动态主题壁纸等。

## 技术栈

- 前端框架：Nuxt3（Vue3 + vue-router4 + Pinia3）
- UI 组件：ant-design-vue 4、@ant-design/charts、@ant-design/graphs、@ant-design/icons-vue
- 国际化：@nuxtjs/i18n 10.5（`i18n/`、`locales/`）
- 实时通信：socket.io-client（消息）、peerjs + simple-peer（WebRTC 音视频通话）
- 内容渲染：markdown-it + highlight.js、dompurify（XSS 清洗）
- 其他：colorthief（主题取色）、gsap（动效）、dayjs、axios、js-cookie、simple-mind-map
- 桌面壳：Electron 42 + electron-builder 24
- 构建工具：Vite（Nuxt 内置）、eslint、prettier、vitest

## 仓库结构

主目录 `JiWu-chat-app/`，与后端实时服务 `JiWu-chat-node/`（独立 Node 服务）同属 pnpm 工作区。

```text
JiWu-chat-app/
├─ assets/          样式与字体（scss/css/woff2）
├─ components/      90+ Vue 组件
├─ composables/     Nuxt 组合式函数（如 useWallpaperPreview）
├─ config/          运行配置
├─ constants/       常量
├─ electron/        Electron 主进程 / preload / IPC
├─ i18n/ locales/   国际化
├─ layouts/ pages/  页面与布局
├─ plugins/         Nuxt 插件
├─ public/          静态资源（theme 壁纸、logo、Ringtone）
├─ scripts/         构建脚本（generate-wallpapers / copy-dist / clean-release / after-pack）
├─ stores/          Pinia 状态（含 dynamicWallpapers.generated.ts）
├─ untils/ utils/   工具函数（注意 untils 为历史拼写目录，仍在使用）
├─ server/          服务端（若启用 Nitro server）
├─ nuxt.config.ts   核心配置
└─ package.json     脚本与 electron-builder 配置
```

## 关键基线指标

- 安装包：经体积优化后仅产出 `JiwuChat_1.0.4_x64-setup.exe`（nsis，x64 单架构）。
- 主题资源：`public/theme` 约 46 个动态背景（mp4 + 抽帧 jpg 封面）。
