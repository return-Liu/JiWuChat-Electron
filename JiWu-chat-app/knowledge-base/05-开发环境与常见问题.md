# 开发环境与常见问题

## 启动命令

```bash
pnpm install         # 安装依赖（postinstall 会跑 nuxt prepare）
pnpm dev             # Web 开发
pnpm electron:dev:full  # 桌面开发（Nuxt dev + Electron）
pnpm lint            # ESLint 自动修复
pnpm format          # Prettier
pnpm test            # Vitest
```

## 目录约定

- `stores/dynamicWallpapers.generated.ts` 由脚本生成，**不要手改**；改主题请改 `public/theme` 后跑 `pnpm wallpapers`。
- `utils/` 为新增规范目录；历史拼写目录 `untils/`（32 个 ts）仍在使用，迁移需谨慎。

## 常见问题

### 本环境无法完整打包

部分受管环境注入「safe-delete」防护钩子，拦截单次删除 >500 文件的 `fs.rm`，
导致 `nuxt generate` 清理 `.nuxt/dist` 或 `electron-builder` 清理解包目录时中止。
**解决**：在本机未注入该钩子的终端（普通 CMD/PowerShell）执行 `pnpm electron:build:prod`。

### 壁纸 URL 变成远程但开发要走本地

确保仓库内 `dynamicWallpapers.generated.ts` 为本地 `/theme` 路径；远程仅在桌面打包时由运行时 base 注入。
若发现开发态走了链接，重跑 `pnpm wallpapers` 重新生成本地清单即可。

### i18n

使用 `@nuxtjs/i18n`，语种文件在 `locales/`，配置在 `i18n/`。新增文案走对应 locale 文件。
