# 动态主题与壁纸系统

## 资源与生成

- 源资源：`public/theme/` 下约 46 个动态背景（`*.mp4`）+ 对应抽帧封面（`posters/*.jpg`）。
- 生成脚本 `scripts/generate-wallpapers.js`：
  - 扫描 `public/theme` 视频，用 `@ffmpeg-installer/ffmpeg` 抽取首帧作封面到 `public/theme/posters/`。
  - 汇总为 `stores/dynamicWallpapers.generated.ts`（`name`/`type`/`url`/`poster`）。
  - 已翻译的中文名以 `/theme/...` 路径为 key 持久复用，切换 base 不丢失。
- 手动触发：`pnpm wallpapers`。桌面打包由 `generate:dist` 自动调用。

## 运行时 URL 解析（关键）

生成文件**永远输出本地路径** `/theme/...`；远程基址仅在运行时按环境变量拼接，避免污染源码、构建失败也安全。

```ts
// utils/wallpaper.ts
export function resolveWallpaperUrl(url?: string): string {
  if (!url) return "";
  const base = (useRuntimeConfig().public as Record<string, unknown>).wallpaperBase as string || "";
  if (!base) return url;
  return url.startsWith("/") ? `${base}${url}` : url;
}
```

- `nuxt.config.ts` 暴露 `runtimeConfig.public.wallpaperBase = process.env.NUXT_PUBLIC_WALLPAPER_BASE || ""`。
- 桌面打包脚本注入 `NUXT_PUBLIC_WALLPAPER_BASE=https://jiwuchat.com`。
- 消费点：`stores/siderColor.ts`（聊天背景实际 URL）、`composables/useWallpaperPreview.ts`（设置面板卡片）。

## 行为矩阵

| 场景 | wallpaperBase | 结果 |
|---|---|---|
| `pnpm dev` 开发 | 空 | 本地 `/theme` 动态主题 |
| Web 部署 | 空 | 本地（同源托管） |
| 桌面打包 | `https://jiwuchat.com` | 运行时从 CDN 拉视频，安装包不含 145MB 视频 |

## 离线兜底

安装包保留 `posters/*.jpg`（0.44MB）。无网络时动态视频空白，但封面与聊天功能不受影响。
