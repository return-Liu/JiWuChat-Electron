## 如何用 RAGFlow 接入本知识库

> RAGFlow 是 InfiniFlow 开源的 RAG 引擎，擅长基于文档的精准问答。本知识库全部为 Markdown，且统一使用 `#`/`##` 标题层级，正好契合其「按标题分块 + 布局感知解析」。

### 1. 部署 RAGFlow

> RAGFlow 依赖 Elasticsearch / Redis / MinIO，官方推荐用 `docker compose` 一站拉起，单独的 `docker run` 无法独立运行。

```bash
# 方式一（推荐）：克隆官方仓库，自带全套依赖
git clone https://github.com/infiniflow/ragflow.git
cd ragflow
# 想用更轻量镜像，可先改 docker/.env：RAGFLOW_IMAGE=infiniflow/ragflow:nightly-slim
docker compose -f docker/docker-compose.yml up -d

# 方式二（不想克隆）：单独下载 compose 文件后启动
curl -sSL https://raw.githubusercontent.com/infiniflow/ragflow/main/docker/docker-compose.yml -o docker-compose.yml
# 视情况调整镜像后：
docker compose up -d
```

启动后访问 `http://localhost`（默认 80 端口，被占用可在 compose 里改端口映射），首次进入需注册账号。
硬件建议：空闲内存 ≥ 10GB，磁盘 ≥ 20GB（镜像 + ES 数据）。

### 2. 创建知识库并上传

1. 进入 `Knowledge` → `Create Knowledge`，数据集名称填 `jiwuchat-kb`。
2. 将本目录（`knowledge-base/`）下所有 `.md` 拖入上传区，等待解析完成。

### 3. 解析与分块配置

- **Parser**：选 `General`（对 Markdown 做布局感知解析）。
- **Chunk method**：`General` / `By title`，并让分块依据标题层级——本库统一的 `#`/`##` 会被良好切分。
- **Chunk token**：建议 `512`，**Overlap** `64`，避免跨章节信息割裂。
- **Language**：`Chinese`。

### 4. 配置检索与对话

1. `Chat` → `Create Assistant`，选择模型（见下）。
2. 在 Assistant 的 `Knowledge` 标签绑定 `jiwuchat-kb`。
3. Prompt 示例：

```text
你是一名「极物聊天」项目助手，仅依据知识库内容回答；
知识库未覆盖时明确说明「知识库未覆盖」。回答使用中文，必要时给出命令或文件路径。
```

4. 检索参数：`Top K = 8`，相似度阈值按需开启（如 0.2）。

### 5. Embedding 模型选择

- 内网/离线：用 **Ollama** 拉起 `bge-m3`，在 RAGFlow `Model Providers` 中配置 `Ollama` 地址（如 `http://host.docker.internal:11434`）。
- 有公网：直接用 RAGFlow 内置或 OpenAI 兼容 Embedding。

### 6. 批量/自动化入库（可选）

用 RAGFlow HTTP API 脚本化：创建 dataset → 上传 document → 触发 parse。可在 CI 中于文档更新后自动重新入库（参考官方 `api/v1` 文档）。
